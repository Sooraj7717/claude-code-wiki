What you should see after each milestone
  • M1: You can start a run and watch one Java/Spring uplift task go through Plan → Implement → Delta → Verify → Complete.
  • M2: You can see a real DAG, multiple tasks and Attempts, recovery/replan history, Human Gates, resume, and live workflow events.
  • M3: You get the complete operator control plane: dashboard, Run Workspace, DAG, Attempts, contracts, verification, diffs, gates, artifacts, audit, security and operational telemetry.
What is deliberately NOT in V6 Parallel execution, Git worktrees, Agent Teams, distributed workers, multi-repository orchestration, automatic commits/pushes/PRs, and autonomous workflow topology remain V7+ candidates.
