FRONTIER — HIERARCHICAL (SUPERVISOR) FLOW
=============================================

Frontier is the single supervisor.
Agents/capabilities perform isolated work and return evidence.
Frontier alone controls state, transitions, scope, recovery, and completion.

AUTHORITY
---------

FRONTIER
  - owns workflow state
  - validates plans
  - controls task readiness
  - enforces write scope
  - decides recovery
  - owns completion

AGENTS / CAPABILITIES
  - inspect, reason, execute, verify
  - return evidence / artifacts / requests
  - never mutate Frontier state
  - never call sibling agents directly

WORKSPACE / GIT
  - authoritative for actual source modifications
