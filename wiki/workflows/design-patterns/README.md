# Dynamic Workflows — HTML Presentation Source

This folder contains the Markdown source used to generate the Dynamic Workflows HTML presentation.

## Structure

- `01-mechanics.md` — why dynamic workflows exist
- `02-patterns.md` — six core workflow patterns
- `03-composition.md` — composing patterns
- `04-sharing.md` — packaging and sharing
- `05-when-to-use.md` — when to use and when to avoid
- `presentation.md` — parent presentation / overview
- `presentation.css` — suggested styling guidance

## Generation model

Each Markdown file represents one HTML page/section. The parent page links to the individual sub-pages.

The Markdown intentionally keeps the same information architecture as the HTML version:
- title and context
- conceptual explanation
- structured bullets
- examples
- flows / diagrams
- practical takeaways
