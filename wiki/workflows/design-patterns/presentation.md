# Dynamic Workflows

> A practical framework for turning complex AI tasks into isolated, verifiable, repeatable workflows.

## Presentation Sections

### 01 — Why Dynamic Workflows?
Context limits, agent laziness, self-preference bias, and goal drift.

### 02 — The Six Core Patterns
1. Classify → Act
2. Fan Out → Synthesize
3. Adversarial Verification
4. Generate → Filter
5. Tournament
6. Loop → Done

### 03 — Compose the Patterns
Combine multiple patterns to create larger task-specific workflows.

### 04 — Package, Save & Share
Treat workflows as reusable artifacts with their instructions, logic, rubrics, and supporting files.

### 05 — When to Use Dynamic Workflows
Use workflows when complexity, isolation, parallelism, verification, or iterative investigation justifies the additional cost.

## Core Mental Model

> **Dynamic workflow = task-specific execution machine**

It combines:
- focused agents
- isolated contexts
- explicit orchestration
- independent verification
- meaningful completion conditions
